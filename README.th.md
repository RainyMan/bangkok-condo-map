# Bangkok condo map

[繁體中文](README.md)｜[English](README.en.md)｜ภาษาไทย

แผนที่โต้ตอบและเครื่องมือค้นคว้าข้อมูลคอนโดในกรุงเทพฯ ใช้ดูโครงการคอนโด สถานีขนส่งสาธารณะ ตัวอย่างประกาศที่มีแหล่งข้อมูล และผลตอบแทนค่าเช่าโดยประมาณ

## ฟีเจอร์

- ดูคอนโดในกรุงเทพฯ พร้อมสถานี BTS, MRT, Airport Rail Link และท่าเรือบนแผนที่
- กรองและเรียงลำดับตามจำนวนห้องนอน ราคารวม ราคาขายหรือค่าเช่าต่อตารางเมตร ผลตอบแทนรายปี ปีที่สร้างเสร็จ จำนวนชั้น และระยะทางถึงระบบขนส่ง
- ตรวจดูข้อมูลโครงการ แหล่งพิกัด ตัวอย่างประกาศ และลิงก์ประกาศต้นทางที่มี
- ประเมินผลตอบแทนรายปีจากตัวอย่างราคาขายต่ำสุดและค่าเช่าต่ำสุดของห้องหนึ่งหรือสองห้องนอน หากพื้นที่ต่างกันเกิน 2 ตร.ม. จะคำนวณโดยใช้ค่าเช่าต่อตารางเมตรต่ำสุดคูณพื้นที่ของประกาศขายราคาต่ำสุด
- แสดงคอนโดใกล้พื้นที่แผนที่ปัจจุบัน และประเมินระยะเดินถึงสถานีขนส่ง

## ข้อมูลและการประเมิน

ข้อมูลโครงการรวบรวมจากแหล่งต่าง ๆ เช่น Hipflat, PropertyHub, DDproperty และ OpenStreetMap โดยจะแสดงลิงก์แหล่งข้อมูลเมื่อมี ข้อมูลพิกัด ประกาศขายหรือเช่า และปีที่สร้างเสร็จมีความครบถ้วนแตกต่างกันในแต่ละโครงการ ราคาและผลตอบแทนคำนวณจากตัวอย่างที่มี โปรดตรวจสอบสถานะปัจจุบันจากลิงก์ต้นทาง การประเมินผลตอบแทนไม่ใช่คำแนะนำด้านการลงทุน

ข้อมูลแผนที่ © [ผู้ร่วมให้ข้อมูล OpenStreetMap](https://www.openstreetmap.org/copyright)

## เปิดใช้งานในเครื่อง

เว็บไซต์เป็นส่วนหน้าแบบสแตติก ไฟล์ที่สร้างแล้วอยู่ใน `dist/` จากโฟลเดอร์หลักของโปรเจกต์ ให้รัน:

```powershell
cd dist
py -m http.server 4173
```

จากนั้นเปิด <http://127.0.0.1:4173/>

## สร้างข้อมูล

โฟลเดอร์ `scripts/` มีสคริปต์ Python สำหรับข้อมูลเว็บไซต์ สถานีขนส่ง เส้นทางเดิน และการตรวจสอบข้อมูล เมื่อต้องการอัปเดต ให้ทำตามคำแนะนำในสคริปต์ที่เกี่ยวข้อง แล้วรัน:

```powershell
py scripts/build_fast_browser_data.py
```

การตั้งค่าเผยแพร่เว็บไซต์อยู่ใน `.openai/hosting.json` โดยใช้ `dist/` เป็นโฟลเดอร์เว็บไซต์สแตติก
